# Side A interface

A task-focused local audio workspace. The user's supplied NekoDJ reference establishes the visual direction: near-black plum canvas, violet controls, lavender waveform bars, rounded track panels, linked/manual compensation, and compact per-track shift and volume controls. System UI type for familiar controls; tabular numbers for timestamps. The signature interaction is a real audio waveform with chapter divisions and a moving playback cursor. Import comes first; the workspace expands after a source is ready. Batch settings sit above the NekoDJ list and apply to explicitly selected tracks. Responsive stacked layout on narrow screens. Clear empty, busy, error, and download states. No remote fonts or assets.

The studio uses a persistent project rail on desktop, a compact project picker on mobile, and a source-first editing layout. Once a source opens, introductory content recedes. The waveform spans the workspace; track editing and a sticky export inspector sit beneath it. Per-track output predictions expose duration, semitone shift, and effectSpeed before export. Advanced finishing controls are collapsed by default. Native output players and explicit folder actions finish the workflow.

Content cleanup lives between the source player and track editor. Scan settings group language/model quality, word dictionaries, custom phrases, and timing margins. Word matches and separately deselected theme signals show context, confidence, editable timing, and a Listen action. Manual marks and original/cleaned players support review. A distinct Apply action controls whether edits affect exports. No UI state claims a moderation pass. Metadata stripping sits in finishing options and explains that technical properties remain.


The batch surface is an Operate workspace: choose sources, import audio, export one ZIP. Source rows carry selection, real native audio previews, status/errors, and Edit cuts. The editor has a prominent return-to-batch action. Shared export controls distinguish whole sources, saved cuts, and fixed-duration parts; uncommon finishing settings stay collapsed. Completed exports lead with download/folder actions and optional individual previews. The app no longer presents a NekoDJ workspace or generates game configs. Preserve the plum/violet identity and use single-column controls on mobile.
